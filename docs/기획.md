# Cosmos: 서울 밤하늘

서울에서 맨눈으로 보이는 하늘을 보여 주는 교육용 웹페이지.

## 범위

인류가 관측한 우주 전체는 데이터가 너무 커서 서비스하기 어렵다. 그래서 **지구(서울)에서 육안으로 관측할 수 있는 우주**로 범위를 정한다.

## 결정 사항

| 항목 | 결정 |
|---|---|
| 기술 | 웹페이지 + Three.js. 서버 없는 정적 파일로 배포 |
| 관측 위치 | 서울 고정 (북위 37.5665°, 동경 126.9780°) |
| 관측 시간 | 페이지를 연 현재 시각 |
| 하늘 밝기 | 낮에도 항상 밤하늘로 보여 준다 |
| 별 | 6.5등급까지, 약 9,100개. 밝기는 크기로, 색은 별의 온도(B-V 색지수)로 |
| 은하수 | 표시하지 않는다. NASA 이미지는 맨눈에 안 보이는 어두운 별빛까지 모여 실제 하늘보다 진하고, 끄니 별자리 선이 또렷하다. 이미지(`public/data/milkyway.jpg`)와 그리는 코드(`createMilkyWay`)는 남겨 두어 다시 켤 수 있다 |
| 태양계 | 달(위상 포함), 수성·금성·화성·목성·토성, 태양(위치만 표시) |
| 늘 보이는 선 | 별자리 선(88개), 흐린 황도 선 |
| 늘 보이는 이름 | 북극성, 황도 12궁 |
| 나머지 이름 | 별자리·밝은 별·행성 이름은 마우스를 올리거나 탭하면 표시 |
| 지평선 | 지평선 아래는 카메라를 둘러싼 밤바다로 가리고 동서남북을 표시. 사방이 바다인 CC0 파노라마 사진이 없어서, 수면 3m 위에서 본 잔물결과 하늘 반사를 셰이더로 계산해 그린다 |
| 조작 | 드래그로 둘러보기만. 확대·이동·그 밖의 기능 없음 |
| 터치 기기 | 짧게 누르면 이름 표시, 끌면 회전 |

## 데이터 출처

| 데이터 | 출처 |
|---|---|
| 별 위치·밝기·색 | NASA HEASARC의 Yale Bright Star Catalog (BSC5) |
| 은하수 (지금은 끔) | NASA Scientific Visualization Studio (SVS) Deep Star Maps |
| 별자리 선 | d3-celestial (BSD 라이선스) |
| 한글 이름 | 직접 작성 |
| 달·행성·태양 위치 | astronomy-engine (MIT 라이선스) |
데이터는 페이지가 열릴 때 외부에서 가져오지 않는다. 개발할 때 한 번 내려받아 변환하고, 결과 파일을 프로젝트에 포함한다.
