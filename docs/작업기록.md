# 작업 기록

## 2026-10-29

### 방향 정하기
- Unity 대신 웹페이지로 만든다. 그래픽은 Three.js(WebGL), 개발 도구는 Vite.
- 범위: 인류가 관측한 우주 전체는 데이터가 너무 커서 서비스가 어렵다. 그래서 **지구(서울)에서 맨눈으로 보이는 하늘**로 줄였다.
- 용도: 교육 자료. 조작은 드래그로 둘러보기만 한다.
- 하나씩 정한 것 (자세한 표는 [기획.md](기획.md)):
  - 관측 위치: 서울 고정
  - 관측 시간: 페이지를 연 현재 시각. 1분마다 다시 맞춘다
  - 태양계: 달(위상), 행성 5개, 태양 위치
  - 낮 처리: 항상 밤하늘
  - 이름 표시:
    - 별자리 선은 늘 보인다
    - 별자리·별 이름은 마우스를 올리거나 탭하면 뜬다
    - 북극성, 황도 12궁, 태양·행성 이름은 늘 보인다
  - 황도 선: 흐린 점선
  - 터치 기기: 짧게 누르면 이름, 끌면 회전
  - 데이터: NASA 자료 위주. 별자리 선은 NASA에 없어서 d3-celestial을 쓴다

### 첫 버전 (커밋 9b5a2a0)
- 별: 밝기는 크기로, 색은 B-V 색지수(별의 온도)로 표현한다.
- 별자리 선을 그리고, 가리키면 그 별자리 선이 밝아진다.
- 태양·달·행성 위치는 astronomy-engine으로 계산한다.
  - 달은 태양 방향에서 빛을 받는 공으로 그려서 위상이 저절로 나온다.
  - 태양과 달은 실제(0.5°)보다 크게 그렸다.
- 지평선, 동서남북, 드래그 회전(아래로는 -10°까지)을 넣었다. 세로 화면에서는 시야를 70°에서 95°로 넓힌다.
- 확인한 것:
  - 북극성은 정북, 고도 36.8°에 뜬다.
  - 아크투루스와 태양 위치가 astronomy-engine의 독립 계산과 0.5° 안쪽으로 맞았다.
  - 별 좌표가 2000년 기준이라 오늘 위치와 약 0.4° 차이가 난다.

### 수정 (커밋 bd2cb63)
- **은하수 끔.**
  - NASA 이미지는 맨눈에 안 보이는 어두운 별빛까지 모여 있어서 실제 하늘보다 진하다.
  - 끄니 별자리 선이 또렷해졌다.
  - 이미지와 `createMilkyWay`는 남겨 두어 다시 켤 수 있다.
- **태양과 행성 이름을 늘 표시한다.** 이름이 천체에 붙어 함께 움직인다.
- **지평선 아래를 밤바다로 바꿨다.**
  - 먼저 Poly Haven의 밤 파노라마 "Moonless Golf"(CC0)의 아래쪽 절반을 입혀 봤다.
  - 그다음 바다로 하기로 했다.
  - Poly Haven과 웹을 찾아봤지만 사방이 바다인 CC0 파노라마는 없었다. 해안에서 찍은 사진은 아래쪽이 모래나 바위다.
  - 그래서 바다를 셰이더로 계산해 그린다: 수면 3m 위 시점, 잔물결, 하늘 반사(프레넬). 물결은 천천히 움직인다.
  - 골프장 사진은 커밋 전에 지웠다.

### GitHub 저장소와 웹서비스
- 저장소: https://github.com/greatkes/Cosmos (계정 greatkes)
  - 처음에는 비공개로 만들었다.
  - GitHub Pages는 무료 계정에서 공개 저장소만 쓸 수 있어서, 이 저장소만 공개로 바꿨다.
- 웹서비스: **https://greatkes.github.io/Cosmos/** (GitHub Pages)
  - `.github/workflows/deploy.yml`이 main에 올라올 때마다 빌드(`npm ci`, `npm run build`)해서 `dist/`를 배포한다. 1~2분 뒤 반영된다.
  - 배포 기록은 저장소의 Actions 탭에서 본다.
  - 배포한 사이트를 열어 개발할 때와 같이 보이고 오류가 없는 것을 확인했다.
- 설정 파일을 올리려면 GitHub 로그인에 `workflow` 권한이 필요했다.
  - `gh auth refresh -h github.com -s workflow`를 실행했다.
  - 브라우저에서 1회용 코드를 넣어 승인했다. 로그인은 사용자가 직접 했다.
- 남은 일:
  - 배포 도구(actions/checkout 등)가 Node.js 20 대상이라 GitHub가 경고를 띄운다. 지금 배포에는 문제가 없지만 나중에 버전을 올린다.
  - 쓰지 않는 은하수 이미지(1.9MB)도 사이트에 함께 올라간다.
